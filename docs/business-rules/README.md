# 业务规则记录

本目录记录 Git Graph 项目的稳定业务规则、核心流程和验证来源。业务规则记录用于辅助二次开发，不能替代源码审查；当文档与源码冲突时，以当前源码和用户确认的需求为准。

## 模块索引

| 模块 | 说明 |
|---|---|
| [Git Graph 核心工作流](modules/git-graph-core-workflow.md) | 扩展激活、仓库发现、提交图加载、Webview 消息、Git 操作、状态持久化和代码评审流程 |

## 使用约定

- 修改业务流程、页面行为、Git 操作、状态持久化、配置导入导出或前后端消息协议时，同步更新对应业务规则记录。
- 不确定的规则必须标记为“待确认”，不能写成已确认事实。
- 每份业务规则记录应包含“业务影响范围”和“测试建议”。
